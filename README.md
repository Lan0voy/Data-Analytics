# Data-Analytics
This repository containing university course implementations of classic data analytic algorithms in tasks from the book: "Learn Data Mining Through Excel: A Step-by-Step Approach for Understanding Machine Learning Methods" by Hong Zhou.

Main folders:

- `Learn-Data-Mining-through-Excel-2-main` — code from the authors of book.
- `Self-study` - my own work with book.
- `study_materials` — additional study materials.
